## Исправление повторной проверки CI

Повторный CI отчёта выявил зависимость теста исторического recovery от текущей
даты: проверка свежести Liquipedia не использовала переданный reference time.
Вызов теперь передаёт то же время, что сохранённое ожидание и остальные
проверки этого пути. Существующий тест воспроизводил ошибку; покрытие не удалялось.

Рабочий production runtime остаётся `bfa3e91`. Исправление явного reference time
проверяется и сохраняется в GitHub для следующего обычного выпуска; новый
облачный deploy этим документационным завершением не выполняется.
