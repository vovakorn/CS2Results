# Матрица публикационных форматов

Актуально для production-состояния на 2 октября 2026 года. Матрица описывает
только реальные контентные форматы; техническая аналитика и тестовые публикации
не включены.

## Обозначения

- ✅ — включено и публикуется;
- 🟡 — работает, но зависит от отдельного флага или может выйти текстом;
- ⚙️ — технически реализовано, но сейчас выключено;
- — — для этой сети формат не реализован.

## Вывод

Локально реализован новый формат «Перед стартом»: Telegram-обложка с паспортом,
полный список команд отдельными слайдами и история/регламент в подписи.
Добавлены независимые Instagram и Threads с тем же альбомом. Threads получает
короткую проверенную историю и полный формат стадий без обрезания обязательных
фактов. В этой версии анонс сохраняет начальный VRS и становится корнем общей
цепочки PandaScore/Liquipedia; следующие посты ждут подтверждения корня.
По умолчанию формат выключен; релиз пока не выполнен, поэтому в таблицу
действующих production-форматов он ещё не включён.
Детали: [`tournament-preview.md`](tournament-preview.md).

Сейчас полноценная рабочая связка — Telegram, Instagram и Threads. Threads
включён в production через собственные claims и outbox при
`ENABLE_THREADS_PUBLISHING=1`; private visual test и реальные штатные
scheduler-выпуски подтверждены. Нативный Instagram → Threads cross-posting для
публикаций, созданных вручную в Instagram, на этот поток не влияет.
Новые Threads-посты группируются в отдельную линейную цепочку каждого ключа
турнира; ранее опубликованные независимые посты не мигрируют. Связь первых
реальных root → reply после релиза ещё требует отдельной проверки. Текущий ключ
содержит источник, поэтому финал Liquipedia может открыть отдельную цепочку от
радара PandaScore того же турнира. Локальная preview-версия устраняет это
для турниров с точным проверенным профилем; для остальных прежний ключ сохраняется.
