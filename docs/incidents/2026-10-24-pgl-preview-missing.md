# PGL Masters: пропуск предтурнирного анонса

Диагностика 24 октября 2026, исходный Git `1f410c9`.

Рабочий реестр содержал только EPL 24. PGL Masters оставался в отдельном
неодобренном реестре примеров, исключённом из function ZIP.
Discovery перебирал только одобренные рабочие профили, поэтому отсутствие
PGL давало пустой успешный ответ. Срок проверки примера от 2 октября
также уже истёк. Это подтверждение невозможности выбрать PGL в этом коде,
а не свидетельство выполнения конкретного production invocation:
чтение Yandex Cloud и получение IAM-токена завершились таймаутами.

[Организатор](https://www.pglesports.com/cs2/pgl-masters-bucharest-2026/)
подтверждает 24–31 октября. Предтурнирное окно 22–23 октября закрыто;
поздняя публикация не выполнялась, claims/markers не менялись.

Исправление включает:
- независимую проверку живого S/A-tier LAN-календаря и план подготовки
  объявленных событий, видимый даже при пустом API;
- уведомления об отсутствующем профиле, просроченном допуске, конфликте дат
  и сбое подготовки, через существующий cooldown;
- три проверенных профиля будущих событий 2026 с ограниченным допуском
  до старта и свежей проверкой паспорта;
- [план 28 событий 2027](../tournament-calendar-2027.md), без выдуманных условий.

Ранние 338 локальных тестов и три обложки прошли проверку до отключения среды.
Объединённая версия проверяется отдельно через CI PR; локальный результат
не заменяет этот CI или live dry-run. Production не менялся.
[Контракт и проверки](../tournament-preview.md).
