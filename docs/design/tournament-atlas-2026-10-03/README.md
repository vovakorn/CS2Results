# Согласованный атлас турнирных тем — 3 октября 2026

Это исходные PNG прежнего атласа, найденные при проверке 26 октября.
Файлы скопированы без изменений; SHA-256 каждого изображения сохранён
в `sha256.json`. Это эталон, а не новая интерпретация оформления.

- [Все 16 образцов](all-styles.png).
- [Шесть ближайших турниров на дату атласа](near-term-styles.png).
- [Уточнённые Thunderpick / FISSURE / CAC](approved-motifs.png).
- `samples/` — отдельные исходные образцы 600 × 480.

Согласование направления и ограничения источников описаны в
[правилах оформления](../../tournament-branding.md).
Образцы не подтверждают даты, участников, выплаты и готовность будущих анонсов.

У IEM Beijing, BLAST Rivals и обычного PGL исходный мотив — тонкие диагонали;
у Singapore Major — более толстые металлические диагонали. Различаются
палитра и мягкое свечение. Другие семьи сохраняют вертикали, сетку,
прицел, импульсы, расколотые плоскости, звезду, молнию и круги.

`tournament_theme_patterns.py` повторяет геометрию и два свечения оригинала
в координатах 600 × 480, затем масштабирует фон под карточку. Проверка
`test_backgrounds_match_unobstructed_edges_of_the_original_atlas` сравнивает
пиксели с исходными PNG во всех 16 образцах; текст и плашки эталона исключены.
