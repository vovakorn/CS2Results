# CS2 Results Bot — краткий контекст

Обновлено: 3 октября 2026 года; production-версия, настройки и таймеры
сверены после релиза оформления серии.

Этот файл — короткая точка входа для новой задачи Codex. Подробности нужно читать
по ссылкам только тогда, когда они относятся к запросу.

## Цель

Telegram-канал `@cs2_results` публикует расписание и результаты заметных матчей
CS2 без информационного шума. Ближайшая продуктовая цель — стабильный первый канал и 1 000 подписчиков; сеть каналов не запускается до подтверждения качества и спроса.

- Reel локально оформляется по точному профилю турнира: цвет, официальный
  логотип и полупрозрачная копия на всех сценах; в смешанном дне блоки индивидуальны,
  общая шапка нейтральная. Демореестры BLAST/PGL в production не подключались.
  Музыка и доставка прежние; чередование двух звуков пока не подключено.
- MVP работает в production на Yandex Cloud Functions, runtime Python 3.12.
- Instagram и Threads OAuth подтверждены для `@cs2results`. Независимая
  Threads-доставка карточек через Xray, Lockbox и public media bucket включена
  в production (`ENABLE_THREADS_PUBLISHING=1`). Telegram proxy не участвует.
  Private visual test и реальные штатные scheduler-посты подтвердили доставку
  branded PNG-карточек в Threads.
- С 21 сентября Threads связывает новые карточки турнира через подтверждённый
  tail: радар, расписание, результаты, итоги и VRS используют общий механизм
  root/reply и отдельное состояние по ключу турнира. Неопределённый исход
  блокирует только этот ключ до ручной проверки; старые посты не мигрируют.
  С 2 октября у турниров с preview-профилем общий ключ PandaScore/Liquipedia,
  корнем является анонс. У остальных ключ включает источник: их финал Liquipedia
  может открыть отдельную цепочку; точные связи остаются задачей развития.
- Последний production-деплой: 3 октября 2026 в 16:49 МСК, версия `d4em256tt14e9ssktmob`
  из Git `146c79c` (PR #132); прежняя `d4ectvltcablmvlapuqa` закреплена
  для rollback. Candidate и production smoke прошли без публикаций;
  все семь таймеров вызывают `production`.
  Прежние настройки и Lockbox references сохранены.
- Telegram Bot API направляется через `TELEGRAM_PROXY_URL` из отдельного
  Lockbox-секрета; подключение подтверждено запросом счётчика подписчиков и
  отдельным тестовым PNG-постом.
- В production включены карточки гранд-финала Liquipedia
  (`ENABLE_LIQUIPEDIA_FINAL_CARDS=1`); Liquipedia fallback по-прежнему выключен.
  Карточка финала использует яркую металлическую золотую фактуру, компактные
  логотипы в отдельном ряду и симметричную композицию вокруг крупного счёта.
  С 3 октября финал и итоги используют цвет и логотип точного профиля анонса,
  включая полупрозрачную фоновую копию. Золотые счёт и приз, медали и спокойный
  фон сохранены. Шапки выровнены; оформление итогов подключено во всех трёх сетях.
- Handler: `cs2bot.main.handler`.
- Новые результаты проверяются каждые 15 минут; отдельный `retry_only` trigger
  обрабатывает durable outbox каждые 5 минут. Расписание публикуется в 09:00,
  итог — в 23:00 по Москве. Таймер радара на 12:00 приостановлен:
  сверка после релиза подтверждает шесть ACTIVE и один PAUSED, все на `production`.
  Discovery анонсов запускается ежедневно в 18:00 МСК.
- Основной источник — PandaScore. Liquipedia работает в shadow-режиме;
  production fallback пока выключен.
- Итоговый VRS-альбом использует официальные versioned Markdown-снимки Valve из
  `counter-strike_regional_standings` (`live/global`); baseline фиксируется при
  анонсе турнира один раз по общему ключу розыгрыша; повтор его не заменяет.
  Радар больше не сохраняет начальный снимок и остаётся PAUSED.
  After — после ближайшего обновления рейтинга. Формулировка публикации
  указывает на изменение после турнира и не приписывает ему события между
  снимками. Флаг `ENABLE_VRS=1` включён в production 10 сентября 2026.
- Доставка защищена per-channel claims и дедупликацией в Object Storage. После
  подтверждения Telegram claim фиксируется как `sent`, затем создаётся processed
  marker; незавершённый marker восстанавливается без повтора сообщения. При
  неопределённом исходе Telegram повтор и fallback запрещены, claim сохраняется
  для диагностики, а администратор получает алерт.
- В production закрыт риск дубля после истечения
  lease: непосредственно перед внешним запросом claim становится
  неперехватываемым `attempting`, неоднозначный ответ — `uncertain`. У такого
  результата outbox удаляется; повтор возможен только вручную после проверки
  платформы. Безусловный lifecycle для всего `claims/*` запрещён.
- Нормализованные результаты сохраняются в durable outbox до подтверждённой
  доставки. Production читает все страницы prefix до глобальной
  сортировки, поэтому lexicographically поздние ключи не голодают.
- Для результата Telegram PNG делает до двух безопасных попыток по 10
  секунд при `ConnectTimeout`, затем в том же invocation пробует текст и на час
  включает text-only режим. Только неудача текстового соединения оставляет
  outbox следующему пятиминутному trigger. Metadata claims читаются
  регистронезависимо для совместимости с Yandex Object Storage
  (`Delivery-State`/`Expires-At`).
- Карточки результатов поддерживают 1–10 матчей, расписание — 1–20 матчей с
  разбиением на две страницы.
- Карточки итогов турнира используют круглые золотую и серебряную медали
  и равномерно обведённую шапку таблицы. Отдельное четвёртое место без медали,
  третье и подтверждённое разделённое «3–4» — бронзовые.
- Tier-1 фильтр расписания использует явно распознанные турниры и PandaScore tier
  `S`/`A` после жёстких исключений; production dry-run 2 сентября отклонил все
  34 низкоуровневых матча дня, включая IEM/FISSURE qualifiers. Для результатов
  действует отдельный строгий Tier-1 LAN-фильтр.
- StarLadder StarSeries явно признан Tier-1 LAN: PandaScore может не передавать
  локацию матча, поэтому подтверждение не зависит от этого поля; qualifiers по
  прежним жёстким исключениям не проходят.
- Код discovery радара ищет Tier-1 турнир на следующий день, сверяет фактический
  самый ранний матч среди всех статусов PandaScore и публикуется только при
  подтверждённых парах: до 24 пар, по 4 на PNG-карточку в альбоме. Авторадар
  дедуплицируется стабильным ключом tournament ID и канала; ручной выпуск остаётся
  дневным. Автоматический таймер сейчас PAUSED.
- Секреты хранятся в Yandex Lockbox. Функция не должна быть публичной.
- Перед этим релизом реальный Object Storage probe подтвердил атомарность
  conditional PUT: один успех из десяти параллельных create-claim и отказ
  устаревшего ETag при перехвате claim.

## Неподвижные ограничения

- Не публиковать пустые выпуски и низкокачественные матчи ради частоты.
- Для матчей, результатов и радара не смешивать разные источники в одной
  выдаче. Превью использует отдельный контракт с происхождением каждого блока;
  отсутствующие данные не выдумываются.
- Не допускать повторной публикации при повторах invocation или переключении
  источников.
- Не раскрывать токены, ключи, секреты и приватный admin chat ID.
- PR, merge, deploy и Telegram-публикация требуют явного разрешения пользователя.
